# cosmowarp-perp-dex

Interact with the Cosmowarp perpetual futures market contracts on Injective testnet.

## Usage

Use this skill when the user wants to:

- Query perp contract metadata, oracle prices, pool state, or positions
- Open, adjust, update, or close leveraged long/short positions
- Work with limit orders, liquidation sweeps, or closed-position history
- Build or debug a frontend that talks to the Cosmowarp perp contracts

## Install

```bash
npx skills add https://github.com/InjectiveLabs/agent-skills --skill cygnus-perp-dex
```
